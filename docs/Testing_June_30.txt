PHASE 1: LOCAL DEVELOPMENT TESTING
==============================================================================

Prerequisites Setup
-------------------
1. CREATE ENVIRONMENT FILE (.env)
   - GEMINI_API_KEY=your_gemini_api_key_here
   - DEBUG=True
   - ENVIRONMENT=development
   - HOST=0.0.0.0
   - PORT=8000

2. INSTALL LATEX DEPENDENCIES
   macOS: brew install --cask mactex
   Ubuntu: sudo apt-get install texlive-full
   Windows: Install MiKTeX or TeX Live

3. PYTHON ENVIRONMENT SETUP
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt

4. DATABASE INITIALIZATION
   - SQLite database will be auto-created on first run
   - Sample data loaded in development mode
   - Located at: data/database/tailer_v2.db

Local Testing Steps
-------------------

STEP 1: Backend Service Verification
   Command: uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   
   Expected Output:
   - "Starting TailerAI v2.0 with Master Dataset Architecture"
   - "Database initialization completed"
   - "Application startup complete"
   - Server running on http://0.0.0.0:8000

   Quick API Test:
   curl http://localhost:8000/health
   Expected: {"status": "healthy", "service": "TailerAI v2.0"}

STEP 2: Frontend Access Verification
   Browser: http://localhost:8000
   
   Expected:
   - TailerAI v2.0 dashboard loads
   - Navigation menu displays all sections
   - No JavaScript console errors
   - Static assets (CSS/JS) load properly

STEP 3: End-to-End Workflow Testing

   3A. JOB ANALYSIS INTERFACE
   Navigate to: Job Analysis section
   
   Test Cases:
   ✓ Paste job description (minimum 50 characters)
   ✓ Character counter updates in real-time
   ✓ File upload (TXT/PDF/DOCX support)
   ✓ Analysis button enables when requirements met
   ✓ Progress indicator shows during analysis
   ✓ Results display with skills, keywords, ATS data
   ✓ Analysis history saves and displays
   ✓ "Select Content for This Job" button works
   
   Expected Result: Job analysis completes and stores data in session

   3B. CONTENT SELECTION COMPONENTS
   Navigate from: Job Analysis → Content Selection
   
   Test Cases:
   ✓ Job summary displays from previous analysis
   ✓ Master dataset loads (or shows empty state message)
   ✓ Content items display with relevance scores
   ✓ Checkboxes allow manual selection/deselection
   ✓ Auto-select button triggers AI optimization
   ✓ Score preview updates in real-time
   ✓ Section controls (Select All/Clear All) work
   ✓ Optimization settings affect scoring
   ✓ "Generate Resume" button enables with selections
   
   Expected Result: Content selected and metrics calculated

   3C. RESUME PREVIEW FUNCTIONALITY
   Navigate from: Content Selection → Resume Preview
   
   Test Cases:
   ✓ Content summary displays selected items
   ✓ Generation settings panel loads
   ✓ Template, font, margin options available
   ✓ Section ordering drag-and-drop works
   ✓ Auto-generation triggers on content load
   ✓ PDF preview displays in iframe
   ✓ LaTeX source toggle works
   ✓ Download button generates PDF file
   ✓ Generation statistics update
   ✓ Error handling for LaTeX failures
   
   Expected Result: Resume generated and downloadable

==============================================================================
TROUBLESHOOTING GUIDE
==============================================================================

Common Issues & Solutions
-------------------------

1. "Module not found" errors
   Solution: Ensure virtual environment is activated and dependencies installed

2. LaTeX compilation fails
   Solution: Install full TeX Live distribution and verify PATH

3. Gemini API errors
   Solution: Check GEMINI_API_KEY in .env file and API quota

4. Database initialization errors
   Solution: Check write permissions for data/database/ directory

5. Static files not loading
   Solution: Verify FastAPI StaticFiles mount configuration

6. JavaScript console errors
   Solution: Check browser console for specific error details

Expected Error Scenarios
------------------------
- Graceful handling of missing API keys
- Proper error messages for file upload failures
- Fallback behavior when AI services are unavailable
- User-friendly messages for LaTeX compilation issues
